Project Overview

This project is a modern recreation of a dashboard using React, TypeScript, and MUI. It includes:

Inventory Overview

Quick Actions

Recent Leads

Navigation Sidebar

Stats Cards

The project is fully component-based, making it scalable, reusable, and easy to maintain.

Technologies Used

React → Component-based UI library.

TypeScript (.tsx) → For type safety.

MUI (Material-UI) → For pre-built UI components like modals, buttons, tabs, cards, and grids.

CSS / MUI Styling → For responsive and custom styles.
